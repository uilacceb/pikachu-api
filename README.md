
## Pokemon Finder Overview

Pokemon Finder is an interactive web application that allows users to search for and display Pokemon by name or number. The app features dynamic background colors that change based on the Pokemon's type and supports both English and Chinese languages.

## Try it yourself

https://pikachu-api.vercel.app/

## Features

### Pokemon Search
- **Dropdown Search System**: Type a Pokemon name or number and select from matching results
- **Bilingual Support**: Search in English or Chinese
- **Number-Based Search**: Find Pokemon using their Pokedex number

### Visual Display
- **Pokemon Imagery**: High-quality official artwork of each Pokemon
- **Dynamic Backgrounds**: Background color automatically changes to match the Pokemon's primary type:
  - Electric types (like Pikachu) → Yellow background
  - Fire types (like Charmander) → Red background
  - Water types → Blue background
  - Grass types → Green background
  - And many more!
- **Responsive Design**: Works on both desktop and mobile devices

### User Experience
- **Instant Results**: Pokemon display updates immediately after selection
- **Intuitive Interface**: Simple, clean design focused on ease of use
- **Smooth Transitions**: Aesthetic color transitions when switching between Pokemon


## Usage

1. Click on the search box at the top of the page
2. Type a Pokemon name (like "Pikachu" or "皮卡丘") or number (like "25")
3. Select your desired Pokemon from the dropdown menu
4. Watch as the Pokemon appears with a type-matched background color
5. To change languages, click the language toggle button in the corner

## Development Process

### API Integration
The application connects to the PokeAPI to fetch Pokemon data, including:
- Names (in multiple languages)
- Official artwork
